🎨 VA-TA Custom Theme

Установщик персональной темы для va-ta.com/app.

1. Отредактируйте CSS темы

Правки сохраняются в вашем браузере автоматически (localStorage).

2. Установите тему

Нажмите кнопку ниже — скачается файл va-ta-theme.user.js. Откройте его, и Tampermonkey предложит установку. После этого тема будет применяться автоматически на каждой странице va-ta.com/app.

3. Без Tampermonkey (букмарклет)

Если не хотите ставить расширение — перетащите эту ссылку в панель закладок, а потом кликайте её на сайте:

📌 Перетащите меня в закладки

Минус: применять вручную при каждом заходе на сайт.

Что делать, если не работает?

1. Убедитесь, что Tampermonkey (или Violentmonkey) установлен и включён.

2. После установки скрипта перезагрузите va-ta.com/app.

3. Если стили «не видны» — значит, ваши селекторы не совпадают с реальными классами сайта. Откройте сайт, нажмите F12, выберите элемент и посмотрите его классы, затем поправьте CSS выше.

4. После правок CSS нажмите «Установить / обновить тему» заново и подтвердите обновление в Tampermonkey.
